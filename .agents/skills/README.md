# Agent Skills

Use a Skill when its workflow matches the task:

- `feature-implementation/SKILL.md`: implementing an approved feature.
- `debugging/SKILL.md`: diagnosing and fixing a defect.
- `testing-and-review/SKILL.md`: verifying and reviewing changes.
- `database-changes/SKILL.md`: Prisma schema and migration work.
- `git-workflow/SKILL.md`: safe review and local commit workflow.

Skills supplement `AGENTS.md` and the applicable Rules. They do not override explicit user instructions or approval gates.
