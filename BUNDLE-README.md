This archive contains the instruction and documentation files prepared for the service-marketplace project.

Copy the contents of this folder into the root of your repository, preserving the folder structure. Review the resulting diff before using the files. This archive does not include application source code or install these files into your repository automatically.

- `CONTEXT.md`
- `STATE.md`
- `README.md`
- `.agents/rules/`
- `.agents/skills/`
